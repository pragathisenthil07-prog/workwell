# Workwell — Employee Wellbeing Dashboard

## About
Workwell is an employee wellbeing dashboard prototype designed to present general workplace wellbeing trends and support information.

## Features
- Employee and employer dashboard views
- Team wellbeing trend indicators
- Recovery support trend indicators
- Feedback and wellbeing-related insights
- Simple, user-friendly dashboard interface

## Technologies Used
- HTML
- CSS
- JavaScript
- React

## Purpose
The project explores how a dashboard can present workplace wellbeing information in an accessible way.

## Privacy Note
This is a prototype. Any displayed metrics should be treated as illustrative unless connected to verified data. Personal or confidential employee information should not be published.

## How to Run
Open `index.html` in a modern web browser if the project is configured as a standalone HTML file.
